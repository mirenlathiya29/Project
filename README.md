# 1. Library Managment System
The Library Management System is a web-based application built with Django, HTML, and CSS to simplify the management of books in a library. It provides features for both library staff (admins) and members (users) to efficiently manage book records, issue/return books, and track late fees.

Users can register and log in, browse books by category, check available copies, and issue books directly from the system. The application automatically manages book return history and calculates late fees for overdue returns.

This system ensures a user-friendly interface, smooth navigation, and a secure login/signup process, making it ideal for small to medium-sized libraries, colleges, or personal collections.
